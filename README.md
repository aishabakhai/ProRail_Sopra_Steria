# ProRail_Sopra_Steria
AI gestuurde voorspellingen van treinvertragingen met domino-effect. ProRail beschikt over rijke treindata (meerdere vervoerders, infra/capaciteit). De huidige praktijk voorspelt vertraging veelal op basis van tijd en inhaalmogelijkheden of herhaling van historische vertragingen.
